# Sounds

`Move.ogg`, `Capture.ogg`, `Check.ogg` and `GenericNotify.ogg` are the "sfx" sound set from the
Lichess project (https://github.com/lichess-org/lila, `public/sound/sfx`), by
[Enigmahack](https://github.com/Enigmahack), licensed AGPLv3+.

The "Soft tones" option uses no audio files; those sounds are generated in `ui/js/extras.js`.
